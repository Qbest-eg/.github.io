API Documentation

This document details the available API endpoints for performing CRUD operations and custom actions across different modules. All endpoints require a valid bearer token passed in the Authorization header. For JSON payloads, include Content-Type: application/json (or use multipart/form-data for file uploads).

1. Superadmin Endpoints

1.1 Company

(a) List Companies (getMyCompanies)

Method: GET
URL: /api/companies/getMyCompanies/
Description: Retrieves a list of companies.

curl -X GET "http://127.0.0.1:8000/api/companies/getMyCompanies/" \
  -H "Authorization: Bearer <ACCESS_TOKEN>"

(b) List Simple Companies (getMySimpleCompanies)

Method: GET
URL: /api/companies/getMySimpleCompanies/
Description: Retrieves a simplified list of companies.

curl -X GET "http://127.0.0.1:8000/api/companies/getMySimpleCompanies/" \
  -H "Authorization: Bearer <ACCESS_TOKEN>"

(c) Create (Add) a Company

Method: POST
URL: /api/companies/
Description: Creates a new company. Ensure the referenced client and category exist.

Payload Example:

{
  "client_id": "9d781e16-5b59-4fca-8e7b-799282c8c3e9",
  "category_id": 1,
  "name": "Test Company",
  "status": 1
}
curl -X POST "http://127.0.0.1:8000/api/companies/" \
  -H "Authorization: Bearer <ACCESS_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
        "client_id": "9d781e16-5b59-4fca-8e7b-799282c8c3e9",
        "category_id": 1,
        "name": "Test Company",
        "status": 1
      }'

(d) Delete a Company

Method: DELETE
URL: /api/companies/{id}/
Description: Deletes a company by its ID.

curl -X DELETE "http://127.0.0.1:8000/api/companies/1/" \
  -H "Authorization: Bearer <ACCESS_TOKEN>"

(e) Restore a Company (Custom Action)

Method: POST
URL: /api/companies/{id}/restore/
Description: Restores a previously deleted company.

curl -X POST "http://127.0.0.1:8000/api/companies/1/restore/" \
  -H "Authorization: Bearer <ACCESS_TOKEN>"

(f) “Connect” Company (Custom Action)

Method: POST
URL: /api/companies/connect/
Description: Connects a company using additional parameters.

Payload Example:

{
  "company_id": 1,
  "other_param": "value"
}
curl -X POST "http://127.0.0.1:8000/api/companies/connect/" \
  -H "Authorization: Bearer <ACCESS_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{ "company_id": 1, "other_param": "value" }'
